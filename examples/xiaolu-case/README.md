## 一句话结论

投 20 万、占 5%，类案只判返还 **90,692 元**；本案靠 2024 年催款记录救时效，建议**先函后诉**，目标和解 8–10 万，不接受 5 万私了。

## 在律师工作台里怎么看

1. 刷新页面 → 左栏「律师台」→ **客户** → 小卢（已成交、已转案件）
2. 看「邀约铺垫卡」——三条钩子都来自她自己说的话
3. 切到 **案件** → `2026-021 卢某与高某合伙合同纠纷`
4. 右栏产出物点开可看 HTML 报告；`03-法律研究/类案判例/` 里有判决书原文
