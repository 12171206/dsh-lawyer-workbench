# 上传与运行说明（照着点就行）

> 这个包演示一遍完整流程：**材料上传 → 截图 OCR → 聊天诊断 → 三档方案 → 报价单 → 转成案件 → 类案分析**。

## 一、先看包里有什么

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `00-来源与脱敏说明.md` | 真实判决来源 + 脱敏对照 + 真/假边界 | 先读，知道哪些是真实判决、哪些是虚构咨询 |
| `01-类案判决书-黔01民终10998号.md` | 真实判决（脱敏） | 上传为「谈案材料」，也是办案时的类案 |
| `02-聊天记录-小卢-20261102.md` | 虚构咨询记录 | 上传为「聊天记录」 |
| `03-聊天截图-01.png` / `-02.png` | 上面聊天记录的两张截图 | 上传后点「识别截图文字」，验证 OCR |
| `04-类案要点与本案预判.md` | 律师内部判断（时效/金额/三条路） | 上传为「谈案材料」 |

## 二、在工作台里跑一遍（约 3 分钟）

1. 左栏「律师台」→ **客户** 页签 → 左上「新建客户」→ 输入 **小卢**
2. 右栏上传区：把 `02-聊天记录`、`01-判决书`、`04-类案要点` 一起拖进虚线框（或点「上传谈案材料」）
3. 再把两张 `03-聊天截图` 拖进去 → 弹出「已上传，现在做什么？」→ 点 **识别截图文字**
4. 看 `聊天原文-OCR-日期.md` 生成（自动去空格）
5. 材料清单里点 **生成诊断** → 出新会话，AI 读聊天记录 + 类案，输出诊断
6. 诊断出来后点 **生成方案** / **生成报价单**（填三档价）/ **生成决策材料**
7. 客户阶段下拉 → **已报价**（如果还没签）；签约后点 **转成案件**（编号 2026-021）
8. 案件台点开新案件 → 「下一步」开跑，把类案判决放进 `03-法律研究/类案判例/`，出法律研究报告

## 三、这份样本想让你看到什么

| 环节 | 看点 |
|---|---|
| 上传 | 拖拽/选文件/粘贴三种方式；截图自动命名；OCR 自动去空格 |
| 诊断 | 五类顾虑全中（钱/信任/不急/比价/家人）+ 时效风险 + 成交理由来自客户原话 |
| 方案 | 三条路：私了 5 万 / 起诉（预期 7–12 万）/ 先函后诉；三档服务 |
| 报价 | 标的 20 万但预期只有 9 万 → 报价结构必须避开"律师费吃掉一半收益" |
| 转案 | 客户→案件一键建台，诊断/方案带进案件档案 |
| 类案 | 真实判决做锚点，法院说理直接支撑"清算不能由执行合伙人承担" |

## 四、必须知道的两个边界

1. **判决书是真实的**（2023）黔01民终10998号；**聊天记录、私了报价、2024 年催款是虚构的**，只用于演示。
2. **不构成法律意见**：时效是否中断、金额能判多少，必须以原件证据和当地现行裁判口径为准。
