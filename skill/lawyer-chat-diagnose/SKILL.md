# 客户聊天诊断（成交断点诊断）

## 0. 这个技能解决什么

律师的成交断点通常不在话术，在**判断**：聊了十几轮，不知道客户卡在哪、该不该约、约了说什么、什么时候该放弃。

本技能输入一段聊天记录，输出一张**行动单**：不是话术大全，是「判断 + 今天发哪一条 + 什么时候放弃」。

**输入**：聊天记录（粘贴 / 截图 / md 文件）+ 可选背景。
**产出**：`聊天诊断-YYYYMMDD.md`（一页纸）+ 可直接复制的一条微信 + 三档方案要点 + 下一步时间表。

---

## 1. 铁律（违反即失败）

1. **先脱敏再分析**。姓名、手机号、身份证、住址、微信号、账户一律替换为【客户】【对方】【金额】【日期】。原件另存只读，诊断稿只放脱敏内容。
2. **每条判断必须引用客户原话**。写不出原话的结论，删掉。
3. **必须给出"不约"这个选项**，并写清放弃条件。只教怎么约的是销售，不是律师。
4. **不承诺结果**。不写"能赢""能拿回多少""包在我身上"。概率只给区间 + 依据 + 主要变量，标准与 `lawyer-litigation-analysis` 一致。
5. **不做心理操控**。不用内疚、恐吓、假稀缺（"今天不定就涨价""这个价只给你"）逼单。
6. **不确定就标不确定**。只看到半段截图、语音没转写、对方是谁不明，都要写进"信息缺口"，不许脑补。
7. **不要逐句回复**。客户说十句，你只发一条；诊断里也不写"第 3 句应该怎么回"。

---

## 2. 输入检查（缺什么要什么）

| 项 | 必填 | 缺了怎么办 |
|---|---|---|
| 聊天记录 | ✅ | 没有记录只给一句话的，走 quick reply，不做诊断 |
| 时间段与消息条数 | ✅ | 从记录里数；缺就先说"信息不完整" |
| 案由与已知事实 | 建议 | 问一句；不阻塞 |
| 是否已报价、报了多少 | 建议 | 影响阶段判定，必须问 |
| 是否已见面 | 建议 | 决定"约上门"还是"约首次" |
| 对方身份（本人/配偶/股东/员工） | 建议 | 决定决策链判断 |

---

## 3. 执行顺序（8 步，不许跳）

### 第 1 步 完整读取
逐条读，不抽样。产出**读取复查摘要**：时间跨度、消息条数、谁先发起、有无语音/图片/文件未读、有无明显截断。

### 第 2 步 脱敏
出一份脱敏原文另存；诊断稿只引用脱敏后原话。

### 第 3 步 阶段判定
按下表定位（细则见 `references/诊断规则.md` §1）：

| 阶段 | 识别信号 | 默认动作 |
|---|---|---|
| 新线索 | 刚加微信、只问"在吗/多少钱" | 一问一给一约（首轮 3 分钟响应） |
| 已咨询未方案 | 讲过事实、问过几次 | 给路径 + 约见面/电话 |
| 已方案未报价 | 讲过方案、没提钱 | 报三档价 + 约决策人 |
| 已报价未签 | 报了价、在拖 | 异议处理 + 风险逆转 |
| 已沉默 | 3 天以上无实质回复 | 价值跟进，不催单 |
| 已委托待付款 | 口头答应、没签没付 | 成交动作 + 付款节点 |

### 第 4 步 顾虑归类 + 原文证据
用五分类（与 `lawyer-deal-close` 同一套）：**钱 / 信任 / 不急 / 比价 / 家人决策**。
每类写：命中原话（1–3 句）、信号强度（强/中/弱）、判断依据。
信号词典见 `references/诊断规则.md` §2。

### 第 5 步 决策链
谁拍板（本人 / 配偶 / 父母 / 合伙人 / 公司会议）、谁在反对、反对理由、决策人是否见过你。
判断依据：客户提到"要问谁""谁不同意""公司要开会"。

### 第 6 步 障碍排序 + 成交概率区间
按 `references/诊断规则.md` §3 打分，输出：
- 最致命障碍 1 个（不解决它，其他都白做）
- 次要障碍 2 个
- 成交概率区间（高 60–80% / 中 35–60% / 低 10–35%）+ 3 条依据 + 2 个变量

### 第 7 步 邀约决策
按 `references/诊断规则.md` §4 决策树判断：**约 / 不约 / 换方式（电话、材料包、线上）**。
- 若约：给 **3 条钩子**——必须来自客户**自己说过的话**，不是套话。
- 给 **3 版话术**：微信短版（≤120 字）/ 电话开场 30 秒 / 被拒后的挽回。
- 若不约：给替代动作（一页纸材料、同类案流程、10 分钟电话、自测三问）。

### 第 8 步 方案、时间表、合规、落盘
- 三档方案要点（基础/推荐/全程：做什么 / 不做什么 / 谁配合 / 交付时点）
- 报价建议（标的式/阶段式/年费式三选一，写清依据）
- 下一步时间表：今天发什么 / 第 3 天 / 第 7 天 / 放弃条件
- 过 `lawyer-compliance-guard`：不承诺结果、不贬低同行、不泄露隐私
- 落盘（见 §6）

---

## 4. 输出格式（固定，见 `templates/诊断报告模板.md`）

```
一、结论（≤3 句）+ 成交概率区间
二、客户现在在哪（阶段 / 温度 / S-A-B-C 分级）
三、他在犹豫什么（五分类 + 原话 + 排序）
四、谁在拍板（决策链 + 缺谁）
五、该不该约（结论 + 3 条钩子 + 约不到怎么办）
六、今天发这一条（可直接复制，≤120 字）
七、三档方案与报价要点
八、下一步时间表（今天 / 第3天 / 第7天 / 放弃条件）
九、合规自检 + 信息缺口
```

**硬要求**：
- 第六条只能有**一条**消息，不许给"版本 A/B/C 自己选"。
- 第八条必须有**放弃条件**（哪几条出现就停止投入）。
- 第三条每条顾虑都要有原话引用。

## 5. 与其他技能的边界

| 要做的事 | 交给谁 |
|---|---|
| 写起诉状/文书 | `lawyer-doc-drafting` |
| 生成正式三档方案文档 | `lawyer-consult-diagnose` |
| 逐类异议话术库（10 个场景） | `lawyer-deal-close/assets/objections-playbook.md` |
| 首轮响应/7 天触点/预诊问卷 | `lawyer-lead-ops` |
| 胜诉率与诉讼策略 | `lawyer-litigation-analysis` |
| 话术合规扫描 | `lawyer-compliance-guard` |
| 成交后跟进、回款、复购 | `lawyer-followup-grow` |

本技能只负责**判断与下一步**，不代写长文案、不代拟合同、不做法律意见。

---

## 6. 落盘规范

```
客户/<客户名-脱敏>/
  聊天原文-YYYYMMDD.md      ← 脱敏后原文（只读归档）
  聊天诊断-YYYYMMDD.md      ← 本技能产出
  方案-YYYYMMDD.md          ← 客户要方案时（consult-diagnose 产出）
  决策材料-YYYYMMDD.md      ← 家人决策时的一页纸
```

- 成案后：诊断摘要（阶段/顾虑/方案/报价）复制进 `案件-…/00-案件档案/案件基本信息.md` 的"来源"一节，客户目录保留。
- 有 `lawyer_growth/crm` 时：更新线索状态；未成交记原因码 `price / trust / timing / competitor / no_decision / capacity / unqualified / ghost`。

---

## 7. 验收标准

- [ ] 每条顾虑都有客户原话
- [ ] 给了"不约"判断与放弃条件
- [ ] 3 条钩子全部来自客户自己说过的话
- [ ] 今天发的那一条 ≤120 字，无结果承诺
- [ ] 概率给了区间 + 依据 + 变量
- [ ] 决策链写清"缺谁"
- [ ] 合规自检无红线
- [ ] 已落盘到 `客户/<客户>/`

---

## 8. 反模式（出现即返工）

- 把诊断写成"高情商回复大全"
- 没判阶段直接给话术
- 客户明显不匹配（标的小、异地、不愿付费）还硬约
- 承诺结果、暗示胜率、夸大同行的坏
- 用"最后一天优惠""今天定减 2000"逼单
- 忽略决策人：约了本人，签不了
- 只分析"客户人怎么样"，不分析"这单怎么推进"
- 把猜测写成事实（把"可能预算紧"写成"他没有钱"）
