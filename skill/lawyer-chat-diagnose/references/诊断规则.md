# 诊断规则（chat-diagnose 的判定标准）

> 本文件是硬规则。SKILL.md 定流程，这里定"看到什么算什么"。

---

## 1. 阶段矩阵

| 阶段 | 识别信号（客户原话） | 证据要求 | 默认动作 | 典型错误 |
|---|---|---|---|---|
| 新线索 | "在吗""你好""我朋友介绍""咨询怎么收费" | 有 1 轮以上对话 | 一问一给一约（3 分钟首响） | 一上来讲 20 分钟法律分析 |
| 已咨询未方案 | 讲过事实、问过"能不能告/多久/多少钱" | 事实基本清楚、有金额 | 给两条路径 + 约见面/电话 | 只回答不推进，聊成免费客服 |
| 已方案未报价 | 讲完路径、客户问"那要多少钱" | 客户已认可路径之一 | 报三档价 + 约决策人 | 报单一价格，没有退路 |
| 已报价未签 | 报了价，客户"再看看/考虑一下/问别人" | 有明确报价记录 | 异议处理 + 风险逆转 | 反复解释价格，越解释越像心虚 |
| 已沉默 | 3 天以上无实质回复（"嗯""好的"也算沉默） | 最后一条是你发的 | 价值跟进，不催单 | 发"考虑得怎么样了" |
| 已委托待付款 | 口头答应、约了签约时间 | 有明确口头承诺 | 成交动作 + 付款节点 + 合同要点 | 口头答应就以为成了，不催手续 |

**阶段判定优先看客户最后 3 条消息**，而不是整段对话的开头。

## 2. 信号词典（客户说什么 → 归类 → 强度 → 动作）

| 客户原话（或近似） | 归类 | 强度 | 该怎么处理 |
|---|---|---|---|
| "太贵了""能不能便宜点" | 钱 | 强 | 先分清"真没钱"还是"觉得不值"，再换档位，不降价 |
| "我预算只有 X" | 钱（硬约束） | 强 | 直接给基础版，不硬推全程 |
| "你们怎么收费" | 钱（价格敏感） | 中 | 给三档，让客户自己选档，别报单一价 |
| "另外一个律师说 5000 全包" | 比价 | 强 | 用"差在三个地方"拆，不贬低同行 |
| "我朋友说打官司没用/很久" | 比价 + 信任（第三方噪音） | 中 | 给时间预期与执行现实，不否定他朋友 |
| "我先自己试试" | 钱 + 价值不确定 | 强 | 给"自测三问"，把风险具体化；同时给基础版 |
| "我再想想""考虑一下" | 不急 | 中 | 问"最犹豫的是钱还是要不要打"，给具体回头时间 |
| "不着急""等过完年再说" | 不急 | 强 | 讲清时效/举证期限，把"不急"变成具体日期风险 |
| "我得问问我老公/父母" | 家人决策 | 强 | 约决策人同场，或做一页纸决策材料包 |
| "公司要开会定""合伙人不同意" | 家人决策（组织型） | 强 | 要决策会议时间，提供决策材料包 |
| "你办过这种案子吗""你执业多久" | 信任 | 中 | 讲同类案处理流程，不讲"我肯定赢" |
| "能不能保证赢/能拿多少" | 信任 + 结果预期 | 强 | 拒绝承诺，给区间+依据+变量 |
| "要多久" | 时机 | 中 | 给区间与关键节点，不压缩成"很快" |
| "要准备什么材料" | 意向（可推进） | 中 | 说明可代为整理，顺势约 |
| "嗯""好的""谢谢" | 冷 | 弱 | 换媒介（语音/电话），不连发文字 |
| 已读不回 ≥3 天 | 冰 | — | 一条价值跟进，7 天后降频 |
| "我先跟家人商量再说吧，谢谢" | 家人决策 + 委婉拒绝 | 强 | 判断是真决策还是礼貌退出，看是否给时间点 |
| "可以啊，那我们签吧" | 成交信号 | — | 立即给合同+付款节点，24 小时内完成 |
| "我朋友也是律师" | 比价（关系型） | 中 | 问"他那边的方案包含什么"，用差异不贬低 |
| "能不能先帮我看看材料" | 白嫖倾向 | 中 | 给"看材料"的边界：一次 15 分钟口头初判，深入要委托 |
| "你们律所在哪/什么时候方便" | 邀约信号 | 强 | 立刻给两个具体时间段，二选一 |

**强度判定**：强 = 客户重复说过 2 次以上，或伴随放弃/拒绝动作；中 = 说过 1 次；弱 = 暗示。

## 3. 成交概率评分表

逐项打分，得出总分，再映射区间。

| 维度 | 加分 | 减分 |
|---|---|---|
| 阶段 | 已报价未签 +3；已方案 +2；已咨询 +1 | 新线索 0；已沉默 −2 |
| 温度 | 热（主动发材料/问细节/问时间）+2 | 冷 −1；冰 −3 |
| 预算信号 | 明确说预算或问分期 +2 | 只问价不问方案 −1 |
| 决策人 | 本人可拍板 +1 | 决策人缺席 −2 |
| 紧迫性 | 有明确期限（开庭/时效/离职日）+2 | "不着急" −1 |
| 信任 | 主动发材料 +2；问资质 +1 | 质疑专业 −1 |
| 价格阻力 | 未提价格异议 +1 | 嫌贵 −2；明确比价 −2 |
| 第三方 | 无人干扰 +1 | 有人劝退 −1 |

| 总分 | 区间 | 含义 |
|---|---|---|
| ≥7 | 高 60–80% | 只差手续，24 小时内推进 |
| 3–6 | 中 35–60% | 有真实需求，卡在一个障碍上 |
| ≤2 | 低 10–35% | 需要换档位或换人，别投太多时间 |

**输出时必须写**：3 条加分/减分依据（引用原话）+ 2 个能改变结果的主要变量（例如"老公的态度""能否接受基础版价格"）。

## 4. 邀约决策树

```
先问：这单值不值得花时间约？
  ├─ 标的或收费 < 5000 且客户无付费意愿 → 不约，走文字/线上
  ├─ 客户在异地且标的小 → 不约上门，改视频
  └─ 值得 → 继续

能不能约（三个硬条件，缺一不约）
  ① 有明确诉求且事实够（说得出"我要什么"）
  ② 有付费信号（问价/问分期/问范围，而不是只要免费意见）
  ③ 最近 7 天内有主动互动（他还在想这件事）
  → 三条都满足：约；缺一条：先补那一条再约

约什么（按客户省钱心理选）
  · "30 分钟帮你把材料清单理出来"（最低门槛，最有效）
  · "把 2N 和 N+1 的差额算给你看"（有具体产出）
  · "跟你和先生一起聊 20 分钟"（家人决策）
  · "电话 10 分钟"（异地/忙）

钩子必须来自客户自己说过的话（4 种来源）
  1. 他说过的时间点："你提到 11 月 15 号前想定"
  2. 他说过的损失："你说公司只给 2 个月"
  3. 他说过的顾虑："你担心仲裁拖很久"
  4. 他说过的目标："你想拿到 N+1"

约不上（三级挽回）
  第 1 次：换时间（给两个具体时段二选一）
  第 2 次：换形式（电话/视频 10 分钟）
  第 3 次：换载体（一页纸材料包，让他拿去给老公看）
  → 三次都不动：降为月度价值触达，不再主动约
```

## 5. 放弃条件（写进诊断报告第八条）

### 硬放弃（出现任一条就停止投入）
1. 明确说已委托其他律师；
2. 连续 3 次跟进、间隔 >10 天无实质回应；
3. 要求"先免费出完整方案/写完文书"，且拒绝任何付费形式；
4. 明显不匹配：标的小于你的最低收费且不愿付咨询费，或案件类型不是你做的。

### 软放弃（降频，不删）
1. 已沉默 14 天但曾主动咨询过 → 月度触达 1 次；
2. 说"等过完年/等孩子开学" → 记日期，到期前 7 天触达；
3. 只说"再看看"但持续点赞/看朋友圈 → 内容触达，不私聊催。

### 二次激活信号（重新升频）
- 主动发新材料/新截图；
- 问"还没签的话现在还能做吗"；
- 对方态度变化（公司又发通知、对方起诉）；
- 时效/举证期限临近。

## 6. 报价建议映射

| 客户特征 | 报价结构 | 档位建议 |
|---|---|---|
| 个人、金额 5–20 万、在意总价 | 阶段式 + 三档 | 基础（代写+指导）/ 推荐（全程仲裁）/ 全程（含一审执行） |
| 个人、金额 >50 万、财产类 | 标的式（分段递减） | 必须写比例与不含项 |
| 企业、常年需求 | 年费式 | 写服务范围与响应时效 |
| 明显预算紧、但信任你 | 基础版 + 咨询费可抵 | 先低价建立关系，后续升档 |

**风险逆转可用**：阶段验收、分段付款、不含项写清、咨询费可抵。
**禁止**："不成功不收费""无效退款"（风险代理受限，且易被认定为承诺结果）。

## 7. 诊断稿里禁止出现的句子（合规红线）

| 不能写 | 改成 |
|---|---|
| "这个案子能赢/胜算很大" | "按现有材料，主张成立的可能性较高，主要变量是 X" |
| "能拿回 8 万" | "2N 约为 7.2–8.4 万区间，取决于工资基数认定" |
| "那个律师不专业/坑人" | "价格差通常差在工作范围、谁来做、出不出庭" |
| "今天不定就涨价/这个价只给你" | 不写（假稀缺） |
| "不签就等着吃亏吧" | "时效/举证期限是这个日期，逾期会有程序风险" |
| 客户真实姓名+手机号 | 【客户】【电话】 |
| "我帮你搞定/包在我身上" | "我负责的部分是 X，结果取决于 Y" |
| "保证 3 个月拿到钱" | "仲裁一般 45 天，加上可能的起诉与执行，通常 3–6 个月" |
