# 律师工作台 · 使用说明（P1）

> 打开方式：刷新 DSH 页面（Ctrl+R）→ 左栏点 **「律师台」** 一个入口，进去顶部是 6 个页签：**案件 / 客户 / 赛道 / 交付 / 期限 / 设置**
> 工作目录：`C:\Users\you\Documents\律师工作目录`
> 演示数据全部在 `_演示/` 下（带「演示」标）；你自己的真实案卷/客户直接放根目录，两者不会混。

---

## 一、30 秒上手

1. **Ctrl+R 刷新页面**
2. 左栏点 **「律师台」** → 默认在 **案件** 页签
3. 默认选中排最上面的案子（红灯优先），看三栏：
   - 左：案件列表（阶段 + 剩余天数 + 交付进度）
   - 中：案件概况 → **下一步卡** → 本阶段 Checklist → 台账
   - 右：期限与时效 / 交付包 / 产出物
4. 点「下一步」卡上的 **开跑** → 自动新建一个会话，把案件路径、阶段、产出落盘位置都带给 AI
5. 干完活回到「案件」页签，点右上角 **刷新** → Checklist、产出物、期限都会更新

---

## 二、六个页签分别干什么

| 页签 | 什么时候用 |
|---|---|
| 案件 | 每天早上第一站：哪个案子红了、这案子卡在哪、下一步做什么 |
| **建档** | **新客户/新案件进来时：选阶段 → 按槽位传资料（含聊天记录、zip）→ 确认后自动建目录并归类** |
| 客户 | 转销台：顶部转化漏斗（线索→已咨询→已方案→已报价→已成交），下面是客户列表和动作；底部有售后待办 |
| 赛道 | 不针对某个案子，想知道"这类活我能干什么"：8 条业务线 → 阶段（可过滤）→ 功能卡；**先右上角选案件再开跑** |
| 交付 | 看所有案子产出的文书，走没走过审查、导没导出、交没交付；点文件可看报告 |
| 期限 | 只看时间：今天逾期、本周、30 天内，跨案件汇总 |
| 设置 | 看工作目录、技能统计、参考区说明、**备份状态（立即备份）** |

## 三、案件台怎么读

### 灯号规则

| 颜色 | 触发条件 |
|---|---|
| 🔴 红 | 台账里有期限 ≤3 天或已逾期（列表自动置顶） |
| 🟡 黄 | 最近期限 ≤7 天 |
| ⚪ 灰 | 已结案 |

### 中间栏

- **案件概况**：编号、客户、对方、案由、金额、管辖、承办、收费、截止
- **下一步卡**：标题 + 卡点原因 + 产出路径 + 3 个按钮
  - `开跑`：建会话，AI 直接开始做这件事
  - `换一个动作`：这个阶段还有另外 2 个候选动作
  - `标记完成`：不做，只是提醒（目前用 Checklist 勾）
- **本阶段 Checklist**：**点一项 = 打勾/取消**，会弹确认框；确认后写回文件并在时间线追加一行
- **台账**：TF（待证事实）/ E（证据）/ IS（争点）计数，有断点会标出来
- **最后更新**：时间线最后一条的日期 + 记录条数（判断这个案子多久没动了）

### 右栏

- **期限与时效**：只显示台账里填了截止日的项；`剩 N 天` 按颜色标
- **交付包**：22 项完成率 + 六条红线（利益冲突/委托合同/授权书/送达地址/期限台账/原件交接）
- **本阶段产出物**：文件按最近修改排，标"草稿 / 已导出"
- **状态流转**：草稿 → 已审 → 已导出 → 已交付（目前只是提示，还没接按钮）

## 四、四个核心动作

### 1）开跑（最常用）

点任何卡上的「开跑」后会发生三件事：

1. 新建一个**独立会话**，工作区就是案卷目录（所以 AI 能直接读写案卷，不影响你当前这个会话）
2. 自动发一段任务说明：用哪个技能、当前阶段、做什么、产出落哪个目录、5 条硬要求（不覆盖旧文件、法条必须核验、编号回填等）
3. 页面自动跳到那个新会话，你可以在里面继续追问、改稿

**赛道台的开跑**：右上角先选一个案件（下拉框），再点功能卡的「开跑」，操作对象就是那个案子。

### 2）勾 Checklist

点中间栏的 Checklist 项 → 确认 → 写回 `游戏规则`：

- 只改 `00-案件档案/案件生命周期Checklist.md` 的 `- [ ]` / `- [x]`
- 只在 `07-程序记录/案件时间线.md` 追加一行
- 不动任何其他文件

勾错了再点一次就取消（时间线会多一行，属正常留痕）。

### 3）看报告 / 导出

- 在 **客户** 或 **交付** 页签点任意文件 → 进入**报告视图**：markdown 已排版成文档（标题、表格、引用块、清单）
- 点右上 **导出 HTML** → 同一目录生成同名 `.html`（样式已内嵌）
- 点 **导出 Word** → 同目录生成 `.docx`（模板级排版：A4、公文页边距、正文仿宋三号、首行缩进、页码；配置了 `firmName` 会带红头）
- 用浏览器打开这个 html → Ctrl+P → 目标选"另存为 PDF"，就是一份可直接发客户/打印的报告
- 案件台右上还有 **「批量导出 Word」**：该案所有实质文书（不含基本信息/台账/Checklist）一次转完
- 导出文件位置会显示在标题栏（如 `客户/李女士/聊天诊断-20261108.html`）

### 4）转销链路（客户页签）

这是新加的「成交 → 交付 → 售后」闭环，全部在 **客户** 页签里：

1. **顶部漏斗**：线索 / 已咨询 / 已方案 / 已报价 / 已成交 / 已失单 各多少人；点一段筛选列表
2. **点客户**：看阶段、分级（S/A/B/C）、温度、来源、预算信号、下一步、截止
3. **点「开跑」**：按阶段自动跑默认动作——
   - 线索 → 3 分钟首轮响应（lead-ops）
   - 已咨询 → 三档方案 + 约上门（consult-diagnose）
   - 已方案 → 报价（deal-close）
   - 已报价 → 异议处理五分类（deal-close）
   - 已成交 → 转成案件（case-workbench）
   - 已失单 → 原因复盘 / 二次激活（followup-grow）
4. **改阶段**：下拉切换，自动写 `客户/<名>/线索.md` 和 `跟进记录.md`；选「已失单」会要求填原因码（price/trust/timing/competitor/no_decision/unqualified/ghost）
5. **转成案件**：点按钮 → 填编号/名称/承办 → 自动建 `案件-编号-名称/`（10 个目录 + 9 个模板已填好 + 时间线首行），客户阶段自动变「已成交」
6. **售后待办**（右栏底部）：结案但没写回访记录的案件，一键生成 30 天回访

> 成案后回「案件」页签刷新，新案就在列表里；客户和案件靠「线索.md 里的已转案件」和「案件时间线首行」双向留痕。

### 4.1 上传材料（不用学，拖进去就行）

客户台右栏有一块常驻上传区，四种方式随便用：

| 方式 | 怎么操作 | 会存成什么 |
|---|---|---|
| 拖拽 | 把截图/txt 拖到虚线框 | 图片 → `聊天截图-日期-序号.png`；文本 → `聊天记录-日期.md` |
| 选文件 | 「上传聊天记录」/「上传谈案材料」 | 同上，谈案材料保留原文件名 |
| 粘贴 | 把微信文字整段粘进文本框 → 「粘贴保存为聊天记录」 | `聊天记录-日期.md` |
| 识别截图 | 上传截图后点「识别截图文字」 | 离线 OCR 生成 `聊天原文-OCR-日期.md`（自动去空格） |
| 材料清单 | 看缺哪项，点后面的小按钮 | 「生成诊断/生成方案/生成决策材料/生成报价单」直接开跑 |

上传完会自动弹一行提示：**已上传，现在做什么？** → 现在生成诊断 / 识别截图文字 / 稍后。

> **邀约铺垫卡**（客户台右栏，绿色卡）：自动列出他从聊天诊断里说过的原话，并生成一段可改的铺垫草稿（用他的话开头 + 一个具体动作 + "先不用定"）。第一次见面只提"给他什么"，不提委托、价格、保证；「换一版」可切换"用他的话 / 给一份东西 / 带家人"。

**新建客户**：客户台左上「新建客户」，输入称呼即可（自动建目录 + 线索档案）。

> 复杂样本在客户台找 **陈先生**：48 条聊天、五类顾虑全中、对方律师函、和限时限、风险代理、三次反悔——想练手从它开始看。

### 6）防坑与新按钮

| 按钮 / 提示 | 在哪 | 做了什么 |
|---|---|---|
| **生成报价单** | 客户台动作行 | 点「生成报价单」展开**卡内表单**（基础版/推荐版/全程·风险三格，一次填完）→ 生成 md 并自动打开报告视图，可导出 HTML |
| **生成脱敏副本** | 报告视图标题栏（仅 .md） | 生成 `xxx.脱敏.md`，替换手机号/身份证/银行卡/邮箱/微信号，并回报命中数 |
| **演示标** | 案件卡、客户卡 | 说明这条来自 `_演示/`，不是真实数据 |
| **期限黄条** | 案件台中间 | 台账 8 项里只有 2 项有截止日时提示"红灯不会亮"，提醒你先补时效起算点与拟立案日 |
| **未过审查红字** | 交付台右上 | 有 `.docx` 但 `出稿前审查报告.md` 里没有 `review_status: PASS`，会标"未过审查"——不会再假装审过 |

### 7）刷新

每个台右上角都有「刷新」。它会重新读案卷文件——**AI 在会话里干完活、你在别处改了文件，都要点一下刷新**。

## 五、新建一个案子

### 最推荐：用「建档」页签（引导式，不用记目录）

1. **选择建档类型**：新客户（还没成案）/ 新案件（已委托）；填称呼、承办、案由，案件再填编号与阶段
2. **上传资料**：按槽位传——
   - 客户：聊天记录 / 咨询材料（协议、转账、身份）/ 其他
   - 案件：委托与身份 / 聊天记录 / 证据材料 / 法院文书 / 文书草稿 / 类案与法规 / 其他
   - 每个槽位可多选文件，**也可以直接传 zip**（下一步自动展开、逐条归类）
3. **预览归档位置**：每一行显示"文件 → 目标文件夹"；**每行都有下拉可以改**，顶部还有「统一改为」批量移动；确认没问题点「确认归档」

确认后系统自动：
- 建好 10 段案件目录（或客户档案目录）
- 按文件名与槽位把文件放进对应文件夹
- zip 解压后的每个文件单独归类，原 zip 留在 `原始压缩包/`
- 客户档案自动生成 `线索.md`

**归类规则（不保证 100%，预览里能看）**

| 文件名里含 | 归到（案件） | 归到（客户） |
|---|---|---|
| 委托/授权/风险告知/收费 | 00-案件档案 | 咨询材料 |
| 身份证/营业执照/户口 | 00-案件档案/当事人信息 | 咨询材料 |
| 聊天/微信/对话/截图 | 01-材料收集/当事人提供 | 聊天记录 |
| 证据/照片/录音/鉴定 | 02-证据整理 | 咨询材料 |
| 判决/裁定/传票/受理/举证 | 07-程序记录 | 咨询材料 |
| 起诉状/答辩状/代理词/律师函 | 06-文书产出 | 咨询材料 |
| 法规/法条/案例/类案 | 03-法律研究/类案判例 | 咨询材料 |
| 其他 | 01-材料收集 | 其他 |

> 归类靠文件名关键词。名字太模糊（如 `IMG_001.jpg`）会进"其他"，后面对应槽位传一次即可。

### 方式 A（备用）：直接跟 AI 说

在对话框里说：

> 新建案件：编号 2026-016，名称 王某劳动争议，承办律师 唐律师，工作目录 C:\Users\you\Documents\律师工作目录

AI 会用 `lawyer-case-workbench` 技能建好 10 个目录 + 9 个模板 + 台账 + 时间线。建完回「案」刷新就能看到。

### 方式 B：命令行

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.dsh\skills\lawyer-case-workbench\assets\new-case.ps1" `
  -Root "C:\Users\you\Documents\律师工作目录" `
  -CaseId "2026-016" -Name "王某劳动争议" -Lawyer "唐律师"
```

### 建完至少填这 4 处，否则工作台显示不全

| 文件 | 填什么 |
|---|---|
| `00-案件档案/案件基本信息.md` | 案由、争议金额、管辖法院、当前阶段、下一个动作、截止时间 |
| `00-案件档案/期限与时效台账.md` | 第 1 项时效起算点、第 2 项拟立案日（**红黄灯全靠它**） |
| `00-案件档案/律师交付包清单.md` | 已到手的改 `✅`，其余保持 `❌` |
| `00-案件档案/案件生命周期Checklist.md` | 做到哪一步就勾到哪一步（**阶段判定靠它**） |

> 解析规则：目录名必须以 `案件-` 开头；上面 6 个文件名不能改。缺文件不会崩，只是对应栏显示"—"。
> 阶段判定 = 「第一个有未打勾项的阶段」与「最后一个有打勾项的阶段」取较大者。

## 六、平时怎么用

### 记住一句话：只有三个时刻必须打开它

| 时刻 | 打开哪个页签 | 干什么 | 花多久 |
|---|---|---|---|
| **每天早上** | 期限 → 案件 | 看谁红了、今天哪个案子该动 | 5 分钟 |
| **来了新咨询** | 客户 | 建档 → 上传聊天 → 出诊断 → 决定约不约 | 10 分钟 |
| **要推进某个案子** | 案件 | 点「下一步 → 开跑」，别在聊天框里重新讲案情 | 1 分钟 |

其他时间想聊天就聊天，不用非开工作台。

### 一天长这样

```
08:50  期限页签    今日/本周谁红了，心里有数
09:00  案件页签    红灯案子点进去，读「下一步」卡
09:05  点开跑      新会话里干活，产出自动落盘
10:30  回案件刷新  勾掉做完的 Checklist 项
整 天  新咨询来了   客户页签：建档→拖聊天记录→出诊断→约不约
16:30  交付页签    今天出的文书有没有"导出未审"的
17:00  客户页签    明天该跟进谁（看截止日）
```

### 每周五 15 分钟（复盘，别省）

1. **交付页签**：红色「未过审查」有几份？补跑出稿前审查。
2. **客户页签**：漏斗哪一段掉得最多？（线索多但咨询少 = 首响问题；咨询多但报价少 = 方案问题）
3. **失单客户**：原因码是否都填了？（price/trust/timing/competitor/...）
4. **案件页签**：有没有"阶段 30 天没动"的案子？

### 每月一次

- 看一遍 `_演示/` 要不要清掉，真实案卷是否都在根目录
- 导出一份客户报价单存档（价格调整前留底）
- 备份 `律师工作目录`（复制到网盘/移动硬盘）

### 两种入口，别搞反

| 你手上是 | 去哪里 | 因为 |
|---|---|---|
| 一个还没签的咨询 | **客户** | 客户台管"成交前"：诊断、方案、报价、邀约 |
| 一个已经委托的案子 | **案件** | 案件台管"成交后"：阶段、证据、文书、期限 |
| 一类活想看看能做什么 | **赛道** | 8 条业务线的功能卡 |

**最常见的错误**：在聊天框里从头描述"我有个案子，当事人叫……"。
正确做法：去案件台点「开跑」，它会自动带上案件路径、阶段、台账、目标产物——你不用复述。

### 六条日常习惯（养成后省一半时间）

1. **上传优先传导出的 txt**，截图只作补充（OCR 有错字，重要节点要对照原图）。
2. **开跑之后补一句话**：在自动生成的会话里加一句"我最在意的是 X"，比让它自由发挥准得多。
3. **干完就勾 Checklist**：阶段判定和红灯全靠它，不勾等于没干。
4. **失单必填原因码**：不填，月底复盘就是瞎猜。
5. **给客户的文书先导出 HTML**，再打印成 PDF 发出去（工作台里点两下）。
6. **每周扫一眼"导出未审"**：没审就发出去的文书，风险你自己担。

### 新增的四个小开关（v5）

| 功能 | 在哪 | 干什么 |
|---|---|---|
| **补到已有** | 建档 → 第 1 步「补到已有」 | 中途收到的材料直接归档进原案卷，不新建目录 |
| **隐藏演示** | 顶部页头勾选框 | 只看真实数据，偏好会记住 |
| **查看全部** | 案件台「本阶段产出物」底部 | 产出超过 8 条时展开 |
| **体检** | 设置页 | 工作目录、案件模板、待归档批次、操作日志是否正常 |
| **导出日历** | 期限台右上 | 生成 `.ics`，导进 Outlook/手机日历，期限到点提醒 |
| **Ctrl+K** | 任意页面 | 搜案件/客户/文件，↑↓ 选、Enter 打开 |

### 三个不要

- 不要把工作台当聊天框（它不会自动知道你在说哪个案子）
- 不要所有事都点开跑（先看诊断/方案，再决定要不要花这一次）
- 不要上传未脱敏的身份证、银行卡原图（手机号身份证号先打码）

## 七、改配置 / 停用

| 想做什么 | 怎么做 |
|---|---|

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 左栏没有「律师台」 | 先 Ctrl+R；仍没有 → 确认插件已启用（插件管理里搜 lawyer-workbench） |
| 数据不更新 | 点对应台右上角「刷新」；确认文件确实变了 |
| 某个案子不显示 | 目录名不是 `案件-` 开头，或不在配置的 `caseRoot` 下 |
| 阶段显示不对 | Checklist 打勾顺序乱了；阶段取「第一个未完成」和「最后一个有进度」的较大者 |
| 红黄灯不亮 | `期限与时效台账.md` 的「截止日」列没填 `YYYY-MM-DD` |
| 交付台文件分类奇怪 | 这是按文件名/扩展名推断的：`.docx`→已导出，名字含"审查/审核"→已审，在 `07-交付文件`→已交付，其余→草稿 |
| 上传的截图能自动分析吗 | 图片会存进客户文件夹，但不会自动 OCR；需要读图时在「开跑」里让 AI 读该目录（它会用 read_image） |
| 上传的 docx 能读吗 | 会保存，但工作台不解析；让 AI 用 read 打开，或转成 md |
| 客户台显示图片文件名很乱 | 图片按 `聊天截图-日期-序号` 自动命名；其他文件保留原名 |
| 报价单里是占位符 | 生成时要依次填三档价格；直接回车跳过就用占位符，可重新生成覆盖 |
| 脱敏没命中姓名 | 只处理手机/身份证/银行卡/邮箱/微信号；姓名需人工替换（无法可靠识别） |
| 交付台标了"未过审查" | 该 .docx 没有对应的 `出稿前审查报告.md`（或里面没有 `review_status: PASS`），先跑出稿前审查 |
| 开跑报错 | 看案件台中间的红字；常见是案件目录被移动/改名 |

## 九、它不做的事（边界）

- 不自行推算法定期限：期限只显示你台账里写的日期（避免 AI 算错上诉期）
- 不自动改你的文书：勾选只动 Checklist 和时间线两个文件
- 参考区 150 个海外技能只读，没有「开跑」按钮
- 交付台「已审」现在只认 `出稿前审查报告.md` 的 `review_status`，读不到就标"未过审查"（不猜）
- 报告导出是 HTML（浏览器打印成 PDF）；docx 导出留到 P2 接 `legal-doc-template-export`
- 报价单是固定模板 + 手填三档价，不按标的自动算价
- 售后只算 30/90/365 三个触点并提示逾期，还没有日历提醒
- 不联网、不写飞书（飞书看板是另一个技能的活）
